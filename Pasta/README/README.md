# Portal-do-Jovem-Dev
Conhecimento digital acessível a todos.

O Portal do Jovem Dev é um projeto de extensão voltado à educação digital, com o objetivo de compartilhar materiais educativo gratuitos, incentivar o desenvolvimento de habilidades tecnológicas e ajudar jovens a explorar oportunidades no universo da tecnologia.

## Objetivo do projeto
O objetivo deste projeto é promover o acesso ao conhecimento digital por meio de conteúdos educativos que auxiliem jovens na utilização segura da internet, no desenvolvimento de competências digitais e na preparação para oportunidades profissionais.

## Funcionalidades
 - Página inicial: apresentação do portal e de sua proposta.
 - Biblioteca de materiais: acesso a cartilhas e e-books educativos em PDF.
 - Download de materiais: possibilidade de baixar os conteúdos disponibilizados.
 - Sobre o autor: apresentação do responsável pelo projeto e links para perfis profissionais.
 - Alternância de tema: opção para alternar entre temas claro e escuro.
 - Layout responsivo: interface adaptada para diferentes tamanhos de tela.
 - Navegação intuitiva: menu para acessar as principais seções do site.

## Tecnologias Utilizadas
 - HTML5: estrutura e organização do conteúdo.
 - CSS3: estilização, layout e responsividade.
 - JavaScript: interatividade, navegação e alternância de tema.
 - Font Awesome: ícones utilizados na interface.
 - Google Fonts - Inter: tipografia do projeto.

## Estrutura do projeto

Portal-do-Jovem-Dev/
├── index.html
├── style.css
├── script.js
└── materiais/
    ├── cartilha.pdf
    └── ebook.pdf

## Descrição dos arquivos:
 - index.html: estrutura principal e conteúdo das páginas e seções.
 - style.css: estilos visuais, organizaão dos elementos e adaptação para dispositivos móveis.
 - script.js: funcionalidades interativas do site.
 - materiais/: diretório destinado aos arquivos PDF disponibilizados para download.

## Como executar o projeto
O projeto utiliza HTML, CSS e JavaScript e pode ser executado diretamente no navegador.

1. Clone o repositório: 
  ''' git clone https: '''

2. Entre no diretório:
  ''' cd Portal-do-Jovem-Dev'''

3. Abra o arquivo '''index.html''' no navegador.

Você também pode utilizar uma extensão de servidor local, como Live Server no Visual Studio Code, para visualizar o site durante o desenvolvimento.
